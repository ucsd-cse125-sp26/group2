# Beam VFX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable, color-parameterized instant-hitscan beam VFX (`GreenPlasma` preset as v1) with muzzle flare and impact burst bookends, replacing the `RailGun` weapon's lightning-arc visual.

**Architecture:** New `BeamEffect` class owns a pool of active beams and builds a camera-facing ribbon triangle strip each frame. A new `beam.vert`/`beam.frag` pair renders the strip with 3-layer additive glow, CPU-baked macro sine displacement, and fragment-shader fBm shimmer into the existing HDR target. Muzzle flare and impact burst reuse the existing `ImpactEffect` billboard pool via new `emitBeamImpact` / spark helpers. Per-beam preset data is carried per-vertex so a single draw batches all beams.

**Tech Stack:** C++23, SDL3 GPU (Metal / D3D12 / Vulkan / WebGPU backends), GLSL 450 → SPIR-V → MSL via `spv_to_msl`, GLM math, entt ECS, ImGui for debug UI.

**Spec:** [`docs/superpowers/specs/2026-04-23-beam-vfx-design.md`](../specs/2026-04-23-beam-vfx-design.md)

## Preamble — how TDD works in this plan

This codebase has no test framework (confirmed by exploration — no Catch2/gtest/doctest). Rather than adding one as scope creep, the mechanical invariants from spec §8.1 are checked via a `BeamEffect::runSelfTest()` static method called from `ParticleSystem::init()` in debug builds (`#ifndef NDEBUG`). Failures fire `assert()` and abort in debug, are stripped in release.

This gives us a TDD loop:

1. Write/extend the test body in `runSelfTest()` referencing methods that don't exist yet.
2. Build — expect a compile error (the "failing test").
3. Add the minimal implementation to make it compile and pass.
4. Build + run — expect no assertion fires.
5. Commit.

For VFX tasks where behavior can't be unit-tested (shader output, visual composition), the test is the debug UI button from Task 15: spawn a beam, compare visually to the reference image.

/// @file BeamEffect.hpp
/// @brief Instant hitscan beam VFX (camera-facing ribbon with macro sine + fragment shimmer).

#pragma once

#include "particles/BeamPresets.hpp"

#include <glm/glm.hpp>
#include <cstdint>
#include <vector>

/// @brief Per-vertex data for the beam ribbon triangle strip.
///
/// All per-beam preset state is carried per-vertex so multiple beams with
/// different presets batch into a single draw call.  See spec §4.3.
struct BeamVertex
{
    glm::vec3 position;         ///< World-space, macro sine displacement baked in.
    glm::vec2 uv;               ///< u = along length [0,1], v = across width [-1,+1].
    float     lifeFrac;         ///< age/lifetime, for fragment life-fade.
    glm::vec3 coreColorHDR;     ///< Copied from preset per vertex.
    glm::vec3 glowColorHDR;     ///< Copied from preset per vertex.
    float     noiseScrollSpeed; ///< Copied from preset per vertex.
    float     noiseIntensity;   ///< Copied from preset per vertex.
};
static_assert(sizeof(BeamVertex) == 56); ///< 14 floats; glm::vec3 is 12 bytes, not 16, in this project.

/// @brief Forward-declared camera interface used by buildGeometry.
class Camera;

/// @brief Instant hitscan beam effect pool.
///
/// Owns up to kMaxActive concurrent beams.  Each beam is an instantaneous strike
/// from origin to hit, rendered as a wavy camera-facing ribbon with 3-layer
/// additive glow (shader), fading over `preset->lifetime`.
class BeamEffect
{
public:
    /// @brief Spawn a new beam.  At capacity, evicts the oldest beam.
    void spawn(glm::vec3 origin, glm::vec3 hit, const BeamPreset& preset);

    /// @brief Age all active beams; remove those whose age exceeds their preset's lifetime.
    void update(float dt);

    /// @brief Build camera-facing ribbon geometry for all active beams into `verts`.
    /// @post `verts.size() == activeCount() * (kSegments + 1) * 2` (with degenerate joins for > 1 beam).
    void buildGeometry(std::vector<BeamVertex>& verts, const Camera& cam) const;

    /// @brief Number of currently active (un-aged-out) beams.
    [[nodiscard]] size_t activeCount() const { return beams_.size(); }

    /// @brief Runs mechanical invariant tests. Called from ParticleSystem::init in debug builds.
    /// @return true if all invariants hold; fires assert() on failure.
    static bool runSelfTest();

    static constexpr size_t kMaxActive = 32; ///< Beams beyond this evict the oldest.
    static constexpr int    kSegments  = 24; ///< Spine subdivisions per beam.

private:
    struct ActiveBeam
    {
        glm::vec3 origin;
        glm::vec3 hit;
        float     age;
        float     waveSeed;         ///< Per-shot phase randomization.
        const BeamPreset* preset;   ///< Non-owning; presets are static-lifetime.
    };
    std::vector<ActiveBeam> beams_;
};
```

static float randf01()
{
    return static_cast<float>(std::rand()) / static_cast<float>(RAND_MAX);
}

void BeamEffect::spawn(glm::vec3 origin, glm::vec3 hit, const BeamPreset& preset)
{
    // Evict oldest if at capacity
    if (beams_.size() >= kMaxActive)
        beams_.erase(beams_.begin());

    ActiveBeam b{};
    b.origin   = origin;
    b.hit      = hit;
    b.age      = 0.0f;
    b.waveSeed = randf01() * preset.waveSeedRange;
    b.preset   = &preset;
    beams_.push_back(b);
}

void BeamEffect::update(float dt)
{
    // Age and cull
    for (auto& b : beams_)
        b.age += dt;

    beams_.erase(
        std::remove_if(beams_.begin(), beams_.end(),
                       [](const ActiveBeam& b) {

void BeamEffect::buildGeometry(std::vector<BeamVertex>& verts, const Camera& cam) const
{
    verts.clear();
    if (beams_.empty())
        return;

    const glm::vec3 camPos = cam.getEye();

    for (size_t bi = 0; bi < beams_.size(); ++bi) {
        const ActiveBeam& b = beams_[bi];
        if (!b.preset)
            continue;

        const BeamPreset& p  = *b.preset;
        const float lifeFrac = (p.lifetime > 0.0f) ? (b.age / p.lifetime) : 1.0f;

        const glm::vec3 axis      = b.hit - b.origin;
        const float     length    = glm::length(axis);
        if (length <= 1e-4f)
            continue;
        const glm::vec3 beamDir   = axis / length;

        // Pick a stable "up" vector for the sine-wave plane; prefer world-up,
        // fallback to world-right if beam is near-vertical. This plane hosts
        // the macro displacement; the resulting displaced point is then rung
        // perpendicular to the camera.
        glm::vec3 sineUp = {0, 1, 0};
        if (std::abs(glm::dot(beamDir, sineUp)) > 0.99f)
            sineUp = {1, 0, 0};
        const glm::vec3 sineAxis = glm::normalize(glm::cross(beamDir, sineUp));

        const float waveK    = 2.0f * glm::pi<float>() * p.waveFrequency; // rad per metre
        const float ampScale = 1.0f; // future: shape amplitude by lifeFrac if desired

        // Degenerate-triangle join between beams: duplicate last vert of previous,
        // then first vert of this (two extra verts inserted here when bi > 0).
        auto pushWithJoin = [&](const BeamVertex& v, bool firstOfBeam) {
            if (firstOfBeam && !verts.empty()) {
                verts.push_back(verts.back()); // duplicate prev
                verts.push_back(v);            // duplicate this
            }
            verts.push_back(v);
        };

        for (int s = 0; s <= kSegments; ++s) {
            const float u       = float(s) / float(kSegments);
            const float alongM  = u * length;
            const float phase   = waveK * alongM + b.waveSeed;
            const glm::vec3 spine = b.origin + beamDir * alongM
                                   + sineAxis * (std::sin(phase) * p.waveAmplitude * ampScale);

            // Camera-facing ring: widthAxis perpendicular to both spine tangent and toCam.
            // Spine tangent is approximately `beamDir` for our gentle sine; exact tangent
            // isn't needed for visual fidelity at 24 segments.
            glm::vec3 toCam = camPos - spine;
            const float toCamLen = glm::length(toCam);
            if (toCamLen > 1e-4f)
                toCam /= toCamLen;
            else
                toCam = {0, 1, 0};

            glm::vec3 widthAxis;
            if (std::abs(glm::dot(beamDir, toCam)) > 0.99f)
                widthAxis = glm::normalize(glm::cross(beamDir, glm::vec3{0, 1, 0}));
            else
                widthAxis = glm::normalize(glm::cross(beamDir, toCam));

            const glm::vec3 topPos = spine + widthAxis * p.glowThickness;
            const glm::vec3 botPos = spine - widthAxis * p.glowThickness;

            BeamVertex top{};
            top.position         = topPos;
            top.uv               = {u, +1.0f};
            top.lifeFrac         = lifeFrac;
            top.coreColorHDR     = p.coreColorHDR;
            top.glowColorHDR     = p.glowColorHDR;
            top.noiseScrollSpeed = p.noiseScrollSpeed;
            top.noiseIntensity   = p.noiseIntensity;

            BeamVertex bot = top;
            bot.position = botPos;
            bot.uv       = {u, -1.0f};

            const bool firstOfBeam = (s == 0) && (bi > 0);
            pushWithJoin(top, firstOfBeam);
            verts.push_back(bot);
        }
    }
}
```

layout(location = 0) out vec2  vUV;
layout(location = 1) out float vLifeFrac;

## Task 7: Write beam.frag shader

**Files:**

- [ ] **Step 1: Write the fragment shader**

Create `shaders/beam.frag`:

```glsl
/// @file beam.frag
/// @brief BeamEffect fragment shader — 3-layer additive glow + fBm shimmer + life fade.
#version 450

layout(location = 0) in  vec2  vUV;
layout(location = 1) in  float vLifeFrac;
layout(location = 2) in  vec3  vCoreColor;
layout(location = 3) in  vec3  vGlowColor;
layout(location = 4) in  float vNoiseScrollSpeed;
layout(location = 5) in  float vNoiseIntensity;
layout(location = 6) in  float vTime;

layout(location = 0) out vec4  outColor;

// --- Cheap hash-based 2D value noise ---

float hash(vec2 p)
{
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float noise2(vec2 p)
{
    vec2 i = floor(p);
    vec2 f = fract(p);
    float a = hash(i);
    float b = hash(i + vec2(1, 0));
    float c = hash(i + vec2(0, 1));
    float d = hash(i + vec2(1, 1));
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(mix(a, b, u.x), mix(c, d, u.x), u.y);
}

float fbm(vec2 p)
{
    return 0.5 * noise2(p) + 0.25 * noise2(p * 2.03) + 0.125 * noise2(p * 4.07);
}

void main()
{
    float d = abs(vUV.y);   // 0 centre, 1 edge
    float u = vUV.x;        // along length

    // Three additive glow layers -- narrow+hot, medium, wide halo
    float core  = exp(-30.0 * d * d);
    float inner = exp(-6.0  * d * d);
    float outer = exp(-1.5  * d * d);

    // fBm shimmer scrolling along beam length; lifeFrac offsets the pattern
    // so each beam instance has a unique shimmer.
    float n = fbm(vec2(u * 6.0 - vTime * vNoiseScrollSpeed, vLifeFrac * 10.0));
    float shimmer = mix(1.0, 0.6 + 0.8 * n, vNoiseIntensity);

    // Soft fade at the beam ends so they don't cut sharply at origin/hit.
    float endFade = smoothstep(0.0, 0.05, u) * smoothstep(1.0, 0.95, u);

    // Life curve: 10% ramp-in / 40% hold / 50% decay.
    float life;
    if (vLifeFrac < 0.10)      life = vLifeFrac / 0.10;
    else if (vLifeFrac < 0.50) life = 1.0;
    else                       life = 1.0 - (vLifeFrac - 0.50) / 0.50;
    life = clamp(life, 0.0, 1.0);

    // Composite. Core gets an extra 2.5x multiplier on top of its preset HDR
    // intensity to guarantee it blooms white even for dim-tuned presets.
    vec3 rgb = vCoreColor * core  * 2.5
             + vGlowColor * inner * 1.2
             + vGlowColor * outer * 0.35;

    rgb *= shimmer * endFade * life;

    outColor = vec4(rgb, 1.0); // additive blend ignores alpha
}
```

        emitSpark(pos, dir * speed, preset.glowColorHDR, life, 0.05f);
